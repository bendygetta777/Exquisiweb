# Exquisiweb 🌮

A web-based pre-ordering and point-of-sale (POS) management platform designed for campus food establishments.

---

## 📌 Project Overview

Exquisiweb solves operational bottlenecks and long waiting lines during peak hours in university food spots. It provides a dual-channel system:

- **Online Pre-Orders:** Allows students to place orders in advance via bank transfers with automated receipt verification time-windows.
- **In-Store POS System:** Fast-capture interface for cashiers to register counter sales (cash/card) and auto-consolidate daily, weekly, and monthly cash closures.

---

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript, TypeScript
- **Backend:** Node.js with Express
- **Database:** MySQL
- **Libraries & Tools:** TypeScript Compiler (TSC), Axios / Fetch API, Express Router
